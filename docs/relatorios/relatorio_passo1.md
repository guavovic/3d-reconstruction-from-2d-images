Objetivo inicial: Criar um protótipo que gere um modelo 3D básico (como um cubo ou esfera) a partir de uma imagem 2D simples.

Evolução: Aos poucos vou adicionar complexidade, como gerar modelos 3D de objetos mais detalhados (por exemplo, um vaso, uma colher, um animal pequeno).

Inicialmente eu instalei o python mais recente (v 3.13.2). Criei um novo repositório no GitHub, e clonei ele localmente no meu pc utilizando o GitHub Desktop. Instalei o vs code, e instalei também extensões relacionadas ao python.

na pasta de src que criei no projeto, instalei algumas bibliotecas que considerei essenciais nesse primeiro caso (se durante o desenvolvimento do projeto eu descobrir melhores formas de implementar certa coisa, vou alterar e etc.)

a lista de algumas bibliotecas que defini como essências para essa primeira fase foram:
